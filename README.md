# Andrés Santiago Arias — Portfolio

Static, multi-page portfolio built with only HTML, CSS and vanilla JavaScript.

## Local preview

Open `index.html` directly or serve the folder with any static server. No install step or build process is required.

## Publishing checklist

- Set the real production domain in canonical, Open Graph and sitemap values.
- Add the final CV only when a public PDF is ready.
- Review every screenshot for names, contact details, private URLs, tokens and sensitive institutional data.
- Keep metrics and project status grounded in verifiable evidence.
