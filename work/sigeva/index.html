The problem

The system needed to support electoral administration and voting flows with different capabilities for learners, staff and administrators.

Constraints

  • The work happened in a team inside the SENA Software Factory.
  • Each institutional role required a different operational surface.
  • Candidate data and photographs had to move cleanly across the frontend/backend contract.

My responsibility

I worked on the candidate module: candidate CRUD, photograph handling and integration. In one documented version, I also participated as Scrum Master.

Architecture

React 19 + TypeScript + Vite 7 frontend with Bootstrap, React Hook Form and Zod, connected to role-aware API flows and reporting utilities such as Chart.js, jsPDF and xlsx.

React 19TypeScriptRole-aware APIReports / exports

Key engineering decisions

Role-specific workflows

Expose the actions that each institutional role needs: aprendiz, funcionario and administrador.

Validated candidate forms

Candidate creation and editing remain consistent across UI and API boundaries.

Reusable reporting surface

Charts and exports make electoral administration information actionable.

What I built

  • Candidate CRUD and candidate photograph management.
  • Role-based flows for learner, staff and administrator.
  • Charts, PDF reports and spreadsheet exports.

Hard problems

The candidate module had to integrate into a broader electoral system while frontend/backend contracts and team workflows stayed coordinated.

Quality & testing

The project included testing and integration work; detailed artifacts are pending collection for the evidence pack.

Deployment & operations

The system was used in an institutional context. Detailed deployment evidence is intentionally pending.

Results

SIGEVA was selected to represent SENA at the national Software Factory competition, demonstrating teamwork, full-stack delivery and institutional relevance. No numeric outcome is claimed.

What I would improve today

  • Add a sanitized architecture diagram and concrete test evidence.
  • Document final API contracts for each role.
  • Capture the institutional workflow without exposing sensitive information.
