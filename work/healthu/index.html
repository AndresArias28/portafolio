The problem

A gym needed a platform for user management, routines and challenges with authenticated access and validated workflows.

Constraints

  • The team coordinated frontend and backend work through Scrum.
  • The system needed relational data and authenticated sessions.
  • Forms and API responses required validation and predictable errors.

My responsibility

I contributed to full-stack development, frontend/backend integration, Scrum organization and testing.

Architecture

Angular reactive forms → REST API → Spring Boot / Spring Security → JPA → PostgreSQL.

AngularREST APISpring BootPostgreSQL

Key engineering decisions

JWT sessions

Authenticated API requests remain stateless and explicit across the application.

JPA relational model

The data layer represents relationships between users, routines and challenges in a maintainable way.

Reactive forms

User input is validated close to the interface while preserving a clear backend contract.

What I built

  • User management, routines and challenges.
  • Authentication and JWT sessions.
  • Reactive forms, REST integration and relational data handling.

Hard problems

Spring Security and JWT configuration, entity relationships, and keeping Angular validation aligned with backend rules were central challenges.
